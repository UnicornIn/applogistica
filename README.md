Sistema de gestión logística — Plataforma principal

## 🚀 Frontend: React + TypeScript + Vite
Este proyecto usa Vite con React y TypeScript para un desarrollo rápido y eficiente.

### Plugins disponibles
- **@vitejs/plugin-react** — Usa Oxc (optimizador en Rust)
- **@vitejs/plugin-react-swc** — Usa SWC (hasta 20x más rápido que Babel)

### Instalación y ejecución
```bash
# Instalar dependencias
npm install

# Iniciar entorno de desarrollo
npm run dev
